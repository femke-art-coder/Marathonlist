# Marathon-Katalog (Proof of Concept)

## Projektbeschreibung
Dieses Projekt ist ein interaktiver Katalog für Marathon-Veranstaltungen in Deutschland. Ziel war es, eine benutzerfreundliche Oberfläche zu schaffen, über die Läufer Events suchen, filtern und neue Einträge hinzufügen können.

## Technische Umsetzung & "Learning Journey"
Dieses Projekt entstand im Rahmen meines autodidaktischen Einstiegs in die Softwareentwicklung (03/2026)
* **Formular-Logik:** Die Eingabemasken wurden mithilfe von KI-Modellen (Prompt Engineering) entworfen, um komplexe Validierungsschritte effizient umzusetzen.
* **Backend & Daten:** Integration einer Supabase-Datenbank zur Speicherung der Community-Einträge. 
  * *Hinweis:* Die Datenbank-Anbindung ist aktuell pausiert (Projektstatus: Archiviert/Referenz).

## Key Features
- Dynamische Filterung nach Distanz, Ort und Level.
- Community-Driven: Formular zum Einreichen neuer Läufe.
- Responsive Design für mobile Nutzung.

## Reflexion
Das Projekt diente primär dazu, das Zusammenspiel zwischen Frontend-Templates, KI-generierter Logik und Cloud-Datenbanken (BaaS) zu erproben.
